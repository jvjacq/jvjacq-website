# jvjacq.com - Personal Website

Source code for my personal website at [jvjacq.com](https://jvjacq.com). A clean, minimal portfolio site built from scratch with plain HTML, CSS, and JavaScript - no frameworks, no build step.

## Pages

- **Home** - intro, selected work, and a quick about snapshot
- **About** - bio, background, and skills
- **Work** - portfolio of projects and creative work
- **Contact** - links and a contact form

## Stack

- HTML, CSS, JavaScript
- [Inter](https://fonts.google.com/specimen/Inter) + [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) via Google Fonts
- [RemixIcon](https://remixicon.com/) for icons
- Light/dark mode via CSS custom properties and `localStorage`
- Fully static - no backend, no dependencies
